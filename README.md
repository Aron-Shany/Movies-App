# Movies App

A responsive movie browsing app built with React.js. Users log in, browse trending, top-rated and original movies, search, view details and manage their account.

**Live demo:** https://shanymoviesapp.ccbp.tech/login

**Demo login:** username `rahul` / password `rahul@2021`

## Features

- JWT authentication with cookies, plus protected routes
- Home page with a random banner movie and three carousels (Trending Now, Top Rated, Originals) built with React Slick
- Popular and Search pages with pagination
- Movie details page with genres, languages, ratings, runtime and similar movies
- Account page with masked password and logout
- Loading, failure and retry views for every API call
- Fully responsive using CSS media queries
- Custom 404 page

## Tech stack

React.js (class components), React Router v5, JavaScript ES6+, CSS3, React Slick, date-fns, js-cookie, REST APIs

## Run locally

```bash
npm install
npm start
```
